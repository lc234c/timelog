# ⏱️ 工时记录 PWA

个人工时打卡与统计工具，纯前端单页应用，无需后端、无需注册，数据全部存在本地。

> 📱 支持 PWA 安装到桌面，体验接近原生 App。

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 🕐 **智能打卡** | 一键打卡，自动识别早/晚/夜班跨天，支持补卡 |
| 📅 **月历视图** | 直观查看每日打卡状态与工时，颜色区分达标/未达标 |
| 📊 **工时图表** | 柱状图展示每日工时，支持导出 PNG 图片 |
| 🎯 **达标管理** | 自定义每日目标工时，自动统计达标天数 |
| 🔄 **排班设置** | 支持固定班次与轮班模式，可自定义班别时间段 |
| 📤 **数据导出/导入** | 导出 CSV 报表、JSON 备份；可从备份文件一键恢复 |
| 🌙 **深色模式** | 自动跟随系统主题（prefers-color-scheme） |
| 💾 **离线可用** | Service Worker 缓存，断网也能用 |
| 📦 **PWA** | 可安装到手机/桌面，独立窗口运行 |

## 🚀 快速开始

### 在线使用
直接访问部署好的地址即可：
```
https://你的用户名.github.io/仓库名/
```

### 本地运行
```bash
# 克隆项目
git clone https://github.com/你的用户名/仓库名.git
cd 仓库名

# 启动本地服务（任选其一）
python -m http.server 8000
# 或
npx serve
```
浏览器打开 `http://localhost:8000`。

> ⚠️ 不能直接双击 `index.html` 用 `file://` 打开，PWA 和 `fetch` 需要 HTTP 协议。

### 安装到手机/桌面
1. 浏览器打开上述地址
2. 地址栏右侧会出现 **"安装"** 图标（📥），或在菜单中选择"添加到主屏幕"
3. 点击确认 → 桌面/主屏幕出现独立图标，点开即全屏运行

## 🛠️ 技术栈

- **前端**：纯 HTML + CSS + JavaScript（无框架依赖）
- **存储**：localStorage
- **PWA**：Service Worker + Web App Manifest
- **图表**：Canvas 原生绘制
- **部署**：GitHub Pages / 任意静态托管

## 🚢 GitHub Pages 部署步骤

1. 在 GitHub 新建仓库（Public），把本项目所有文件推到仓库根目录
2. 仓库 → **Settings** → 左侧 **Pages**
3. Source 选 **Deploy from a branch**，Branch 选 **main** + 文件夹 **/ (root)**，Save
4. 等待 1~3 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可
5. 以后改了代码，`git push` 后 Pages 自动重新部署；**改了业务代码记得把 `sw.js` 里 `CACHE_NAME` 版本号 bump 一下**，否则用户浏览器仍用旧缓存

## ⚠️ 注意事项

| 事项 | 说明 |
|---|---|
| 数据仅存本地 | 清除浏览器数据会丢失所有打卡记录，建议定期「下载备份文件」 |
| 换设备恢复 | 用「从备份文件导入」选择备份 JSON 即可一键恢复 |
| 代码更新需 bump 缓存 | 修改业务代码后，记得更新 `sw.js` 中 `CACHE_NAME` 版本号 |
| iOS 支持 | iOS 16.4+ 支持 PWA 安装，standalone 模式下部分 API 行为略有差异 |
