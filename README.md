# ⏱️ 工时记录 PWA

个人工时打卡与统计工具，纯前端单页应用，无需后端、无需注册，数据全部存在本地。

> 📱 支持 PWA 安装到桌面，体验接近原生 App。

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 🕐 **智能打卡** | 一键打卡，自动识别早班/晚班/夜班跨天，支持补卡 |
| 📅 **月历视图** | 直观查看每日打卡状态与工时，颜色区分达标/未达标 |
| 📊 **工时图表** | 柱状图展示每日工时，支持导出 PNG 图片 |
| 🎯 **达标管理** | 自定义每日目标工时，自动统计达标天数 |
| 🔄 **排班设置** | 支持固定班次与轮班模式 |
| 📤 **数据导出** | 导出 CSV 报表、JSON 备份，支持系统分享 |
| 🌙 **深色模式** | 自动跟随系统主题 |
| 💾 **离线可用** | Service Worker 缓存，断网也能用 |
| 📦 **PWA** | 可安装到手机/桌面，独立窗口运行 |
